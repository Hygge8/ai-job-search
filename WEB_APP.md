# AI Job Search Web

This repository now includes an optional browser-based MVP in addition to the original Claude Code workflow.

The web application follows the same deployment ideas used by `Hygge8/ai-goofish-smart-monitor`:

- FastAPI backend
- server-side OpenAI-compatible model configuration
- local SQLite persistence
- Docker Compose deployment
- browser UI protected by a username and password
- existing repository CLI tools reused instead of rewriting every job portal integration

The original `/setup`, `/scrape`, `/apply`, `/rank`, and `/interview` Claude Code commands are not removed or changed.

## What the web MVP can do

1. Import the candidate profile generated by `/setup`.
2. Edit and persist the profile through the browser.
3. Search LinkedIn and FreeHire by calling the existing Bun CLI skills under `.agents/skills/`.
4. Merge and deduplicate search results.
5. Paste a full job description and ask an OpenAI-compatible model for a fit evaluation.
6. Generate a targeted application pack containing:
   - application summary
   - CV profile text
   - suggested truthful CV bullets
   - cover letter
   - interview questions and answer points
   - missing-information and honesty checks
7. Store search, evaluation, and generation history in SQLite.

## Important differences from the Claude Code workflow

The web MVP does **not yet** reproduce the entire `/apply` pipeline. In particular, it does not currently:

- spawn a second Claude Code reviewer agent
- modify LaTeX files automatically
- compile and visually inspect PDFs
- run the ATS `pdftotext` verification loop
- log in to BOSS, Liepin, Zhaopin, or other authentication-walled portals
- bypass captchas, anti-bot systems, or portal access restrictions

For Chinese recruitment sites, the recommended workflow is still to copy the complete job description into the web page and run the evaluation or generation action.

## Security model

- `OPENAI_API_KEY` is read by FastAPI from `.env.web` and is never returned to the browser.
- API routes use HTTP Basic authentication configured by `WEB_USERNAME` and `WEB_PASSWORD`.
- The browser stores the Basic credential only in `sessionStorage` for the current browser tab.
- This MVP is designed for local or private-network use. Put it behind HTTPS and a stronger authentication proxy before exposing it to the public Internet.
- Personal profile data and generated results are stored locally in `web-data/app.sqlite3`.

## Docker deployment

### Windows CMD

```cmd
cd /d D:\项目\docker\ai-job-search
copy .env.web.example .env.web
notepad .env.web
docker compose -f docker-compose.web.yml up -d --build
docker compose -f docker-compose.web.yml logs -f app
```

### PowerShell

```powershell
Set-Location "D:\项目\docker\ai-job-search"
Copy-Item .env.web.example .env.web
notepad .env.web
docker compose -f docker-compose.web.yml up -d --build
docker compose -f docker-compose.web.yml logs -f app
```

### Linux / macOS

```bash
cp .env.web.example .env.web
$EDITOR .env.web
docker compose -f docker-compose.web.yml up -d --build
docker compose -f docker-compose.web.yml logs -f app
```

Open:

```text
http://127.0.0.1:8000
```

The initial username and password are the values configured in `.env.web`.

Stop the service:

```bash
docker compose -f docker-compose.web.yml down
```

## Local development without Docker

Requirements:

- Python 3.11+
- Bun

Install the Python runtime:

```bash
python -m venv .venv
```

Windows CMD:

```cmd
.venv\Scripts\activate
pip install -r requirements-web.txt
copy .env.web.example .env.web
python -m webapp.main
```

Linux / macOS:

```bash
source .venv/bin/activate
pip install -r requirements-web.txt
cp .env.web.example .env.web
python -m webapp.main
```

Install the portal CLI dependencies before using browser job search:

```bash
for tool in jobbank-search jobdanmark-search jobindex-search jobnet-search linkedin-search freehire-search; do
  cd ".agents/skills/$tool/cli" && bun install && cd ../../../..
done
```

On Windows PowerShell:

```powershell
$tools = @("jobbank-search", "jobdanmark-search", "jobindex-search", "jobnet-search", "linkedin-search", "freehire-search")
foreach ($tool in $tools) {
  Set-Location ".agents/skills/$tool/cli"
  bun install
  Set-Location "../../../.."
}
```

## Environment variables

| Variable | Purpose | Required |
|---|---|---|
| `OPENAI_API_KEY` | Server-side model credential | Yes |
| `OPENAI_BASE_URL` | OpenAI-compatible endpoint; blank uses the OpenAI default | No |
| `OPENAI_MODEL_NAME` | Provider model name | Yes |
| `AI_TIMEOUT_SECONDS` | Model request timeout | No |
| `WEB_USERNAME` | Browser login username | Recommended |
| `WEB_PASSWORD` | Browser login password | Recommended |
| `SERVER_PORT` | Published web port | No |
| `WEB_DATABASE_FILE` | SQLite database path | No |

## API overview

All `/api/*` endpoints require HTTP Basic authentication.

| Endpoint | Method | Purpose |
|---|---|---|
| `/health` | GET | Health and runtime capability check |
| `/api/config` | GET | Safe configuration status, never returns the API key |
| `/api/profile` | GET/PUT | Read or save the web candidate profile |
| `/api/profile/import-local` | POST | Import the local Claude Code candidate profile |
| `/api/jobs/search` | POST | Search installed portal CLIs |
| `/api/jobs/evaluate` | POST | Evaluate a pasted job description |
| `/api/applications/generate` | POST | Generate a targeted application pack |
| `/api/history` | GET | Read local execution history |
